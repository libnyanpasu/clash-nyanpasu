# sing-box 内核接入 任务卡（S0–S3）

[设计](design.md) 的执行清单。S0–S3 写到 PR 粒度；S4 之后在各阶段开始前按同样粒度补充，里程碑见 [roadmap](../../roadmap/2026-11-11-sing-box-core.md)。

约定：

- 一张卡是一个 PR，一个 PR 做一件事并且能独立构建（`workflow.md` 的提交规则）。改名卡不带行为变更。
- “验证”列的每一项都要能机械地判断通过与否。
- 主仓的卡在开始前按 `workflow.md` 评估是否使用 worktree；runtime 仓的卡在 runtime 仓提交，主仓只更新 pin。
- 涉及命令的卡都要重新生成绑定并在 Tauri IPC 与 HTTP 两个传输上验证（`rpc.md`）。
